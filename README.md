# CombatGame #
This is a recreation of the Atari Combat video game, which I made in my Advanced Programming for Game Development course! We each had to make our own versions of the game, and here are the files for mine. It was a lot of fun to make and to put a spin on one of the games that I grew up playing! 

If you want to see the entire game file/zip, email me for the itch password (you need to be able to run a uproject file)!

# My Contributions #

Game Mechanic Engineering (C++ and Blueprints) - This game was created using a combination of manual C++ programming (attribute sets, random color scheme data table implementation, etc.) and UE5 blueprints (Game UI, HUD, level and bullet type implementation, etc.). There is additional multiplayer functionality as well as options for a controller player and a keyboard player.

Level and Visual Design - In this Atari Combat recreation, we were tasked with making a basic and pre-determined level to start out. However, I created an additional level that players can traverse completely from scratch. This layout significantly changes the play space in addition to the different types of bullets that you are able to use to vary gameplay. I also wanted to separate this recreation a tad stylistically, so I created different designs for the tanks in the game and utilized simple, yet distinct and contrasting color schemes that make it easier for players to distinguish game elements. 

Utilization of GAS (Gameplay Ability System for UE) - With this project, we practiced utilization of UE's GAS, specifically for the abilities of the tanks. The ability for the tanks to shoot bullets required the Ability System, and the 'speed boost' effect utilized gameplay effects that modified the character's speeds temporarily.
